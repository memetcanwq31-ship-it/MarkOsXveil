## Kurulum

```bash
git clone https://github.com/memetcanwq31-ship-it/MarkOsXveil.git
cd MarkOsXveil
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```
